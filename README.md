# Hayzo — منظومة واجهات عربية أولًا

> الاسم مؤقت. المشروع مفتوح المصدر برخصة MIT.

المكتبات الموجودة اتبنت بالإنجليزي وبعدين «اتعرّبت». هنا العكس: العربي هو نقطة البداية في الأرقام، والفلوس، والتواريخ، والاتجاه، والأيقونات، والجداول، وبعدين أي لغة تانية.

## المرحلة الحالية: قاعدة المعرفة (L0)

قبل أي مكوّن، بنجمع **كل البيانات اللي المكتبة هتتبني عليها** في نموذج بيانات واحد مقفول بـJSON Schema:

| المجلد | المحتوى |
|---|---|
| `data/regions` · `data/currencies` | الدول العربية: العملة وكسورها، أول الأسبوع والعطلة، نظام الأرقام، التقويم، المناطق الزمنية |
| `data/language` · `data/calendar` | الجمع العربي، التفقيط، أسماء الشهور بأنواعها، التقويم الهجري |
| `data/phone` · `data/finance` | خطط الترقيم، IBAN، الضريبة، الفوترة الإلكترونية، الأرقام القومية والضريبية |
| `data/catalog` | واجهات كل المكتبات المنافسة (props وأنواعها) + القائمة الموحدة للمكونات اللي هنغطيها |
| `data/patterns` | عقود الكيبورد والـfocus والـARIA لكل نمط تفاعل، ومعاها اللي بيتغير في RTL |
| `data/icons` · `data/fonts` · `data/tokens` | الأيقونات وقواعد عكسها، الخطوط العربية ومقاساتها، مقاييس الأنظمة التانية |
| `data/rules` · `data/fixtures` · `data/field-reports` | القواعد، حالات الاختبار، وأعطال RTL الحقيقية في المكتبات التانية |

كل ملف فيه **مصدره ورخصته ودرجة الثقة فيه**، وأي حاجة اتسحبت بسكريبت السكريبت بتاعها موجود في `tools/extract`.

```bash
pnpm install
```

```bash
pnpm validate
```
